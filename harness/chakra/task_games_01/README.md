# Breakout Clone with Levels (Core Tap)

## Overview
Core Tap is a Breakout/Arkanoid style arcade game written in Python 3.10+ using **Pygame**.  The player controls a deep‑sea survey rig (paddle) that reflects a sonar pulse (ball) to fracture rock strata (bricks) across a chain of drill sites (levels).

## Features
- Multiple JSON‑defined levels (`levels/site_01.json` … `site_03.json`).
- Brick classes: `sediment`, `ore`, `core`, `basalt` (indestructible).
- Four power‑ups (wide rig, split pulse, drag field, spare hull) – simplified implementation.
- Lives (hull integrity) – start with 3.
- High‑score leaderboard (`saves/highscores.json`).
- Pause/resume (P or Esc).
- Snapshot export (`F5`) and import (`F9`) – full game state round‑trip.
- Deterministic RNG per run; snapshots contain the RNG seed.
- Headless preview build (`python -m coretap.preview`) that runs an autopilot rig and writes PNG screenshots and an `index.html` contact sheet.
- Light unit tests (`python -m pytest -q`).

## Quick Start
```bash
# Install dependencies
pip install -r requirements.txt

# Run the game
python -m coretap
```

Controls:
- ← / → or A / D – move the rig.
- Space – launch the pulse (first launch only).
- P or Esc – pause.
- F5 – export snapshot to `saves/snapshot_<timestamp>.json`.
- F9 – import the most recent snapshot.

## Development
- Run the test suite: `python -m pytest -q`
- Generate a static preview build: `python -m coretap.preview`

## Data Files
- `levels/*.json` – level layouts (ASCII grids).
- `saves/highscores.json` – top‑10 leaderboard.
- `saves/snapshot_*.json` – exported snapshots.
