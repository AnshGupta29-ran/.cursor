# Ecommerce Website - ecom_test2

This is a basic ecommerce website structure with login and landing pages.

## Folder Structure

```
ecom_test2/
├── index.html          # Landing page
├── login.html          # Login page
├── products.html       # Products page
├── about.html          # About page
├── contact.html        # Contact page
├── css/
│   └── style.css       # Stylesheet
├── js/
│   ├── main.js         # Main JavaScript functionality
│   └── login.js        # Login-specific JavaScript
└── assets/             # Placeholder for images
```

## Features

- Responsive design
- Basic navigation between pages
- Login form with validation
- Product showcase
- Contact form

## How to Use

1. Open `index.html` in a web browser to view the landing page
2. Click on "Login" in the navigation bar to access the login page
3. The site is fully responsive and works on mobile devices
