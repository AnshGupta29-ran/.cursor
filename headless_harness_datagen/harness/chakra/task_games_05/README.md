# Task 05: Puzzle Game

A simple tile matching puzzle game where players swap adjacent tiles to create matches.

## Features
- Grid-based tile matching gameplay
- Colorful tiles with different colors
- Score tracking
- Tile selection and swapping mechanics

## Controls
- Mouse clicks to select and swap tiles

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the game: `python main.py`

## Game Mechanics
- Click on a tile to select it
- Click on an adjacent tile to swap positions
- Match 3 or more tiles of the same color to score points
- Try to create as many matches as possible
