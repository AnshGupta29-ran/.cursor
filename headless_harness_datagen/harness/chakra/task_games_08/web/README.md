# Deepvault Survey (browser)

ASCII salvage roguelike — TypeScript + Vite + canvas.

## Run

```bash
cd harness/chakra/task_games_08/web
npm install   # once
node node_modules/vite/bin/vite.js --host 127.0.0.1
```

Open the Local URL Vite prints (e.g. http://127.0.0.1:5190/).

## Controls
- Menu: ↑/↓, type seed, Enter
- Move: WASD / arrows (optional hjkl/yubn diagonals)
- Bump into husks to attack
- 1 / 2 / 3 use inventory
- Esc pause · F5 stasis save · F9 stasis restore (tab memory only)
- Reach `>` shafts on floors 1–2; claim `&` Vault Heart on floor 3

## Fiction
You are a Reclamation Surveyor in a flooded pre-Collapse data vault. Enemies: Rust Husk `h`, Sentry Coil `s`, Scav Rat `r`. Items: Patch Kit `+`, Lumen Flare `o`, Spark Charge `*`.
