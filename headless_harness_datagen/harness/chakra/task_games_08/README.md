# Task 08: Strategy Game

A simple resource management strategy game with base building and unit production.

## Features
- Base structure that needs protection
- Resource management system
- Unit spawning (soldiers and workers)
- Score tracking through unit count
- Simple UI with spawn buttons

## Controls
- Click "Spawn Soldier" button to create soldiers ($20 each)
- Click "Spawn Worker" button to create workers ($15 each)

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the game: `python main.py`

## Game Mechanics
- Manage your resources to spawn units
- Soldiers cost more but are stronger than workers
- Workers help gather resources over time
- Protect your base from enemy attacks
- The goal is to manage resources wisely while building up your forces
