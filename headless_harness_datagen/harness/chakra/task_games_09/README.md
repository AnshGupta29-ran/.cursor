# Task 09: Survival Game

A simple survival game where the player must gather resources and avoid enemies to stay alive.

## Features
- Player character with health, food, and water stats
- Resource collection (food, water, health)
- Enemy characters that chase the player
- Score tracking based on resource collection
- Stats display for player status

## Controls
- Arrow Keys: Move around the screen

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the game: `python main.py`

## Game Mechanics
- Control your blue character to survive as long as possible
- Collect green food, blue water, and red health items to restore your stats
- Avoid orange enemy characters that will damage you when they touch you
- Your health, food, and water decrease over time
- The goal is to collect as many resources as possible while avoiding enemies
